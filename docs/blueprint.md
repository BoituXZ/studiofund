# **App Name**: HiveFund

## Core Features:

- User Authentication: Secure registration and login functionality with phone number and password.
- Group Management: Allow users to create, join, and manage groups for collective savings and investment.
- Pool Contribution and Management: Enable members to contribute funds to their group's pool and admins to manage pool balances.
- Investment Proposal and Voting: Admins can propose investments, and members can vote on these proposals within their groups.
- Claim Submission and Approval: Allow members to submit claims for various needs, and other members to vote for their approval.
- Browse Local Businesses: A directory where HiveFund members can find businesses in their region to support. The app lets users see which ones are actively looking for investment, as well as detailed business analytics and financial details. Risk scores for potential investments are automatically computed.
- Discount Redemption: Enable users to view available discounts and redeem them at participating businesses.

## Style Guidelines:

- Primary color: Teal (#0D9488) to inspire trust and financial growth.
- Accent color: Amber/Gold (#D97706) to represent wealth and community warmth.
- Background color: Off-white (#FAFAF9) for a clean, professional look.
- Headings: 'Inter' (sans-serif) Bold for clear titles. Body: 'Inter' Regular (sans-serif) for readable content. Numbers/Currency: 'Inter' Medium (sans-serif) for emphasis.
- Use simple, professional icons; house icon for the Home tab, people icon for the Groups tab, store icon for the Businesses tab, tag icon for the Discounts tab, and user icon for the Profile tab.
- Employ a card-based layout to facilitate easy scanning and clear separation of information. Use consistent spacing and padding for a structured appearance.
- Implement subtle animations for page transitions and interactions to provide smooth feedback, maintaining a fast and fluid user experience. Slide left/right (300ms) for page transitions, slide up from bottom (250ms) for modal opens, and fade in (200ms) for card appearances with ease-in-out timing for all animations.
